# H3 方案五：双人物图 + Opening State

当前默认恢复为原版方案五。每段独立生成，只传入同样的两张人物身份图，不依赖上一段的尾帧图片或参考视频。

| 项目 | 当前用法 |
| --- | --- |
| 本地工作流 | `H3-方案5-女主单图-男主单图-576x960.json` |
| 原名称 | `H3-动态多段-方案5-无Video-OpeningState-576x960.json` |
| 每段参考图 | `<Picture 1>` 女主、`<Picture 2>` 男主 |
| 跨段承接 | 在下一段提示词中填写 Opening State，描述人物位置、姿态、动作阶段和镜头状态 |
| 故事文件 | `story_segments.json`，每段 `raw_prompt: true`，完整六节 `prompt` |
| 时长与分辨率 | 在工作流中设置；默认尺寸 576×960（3:5），时长不放进故事 JSON |

第一段、第二段和后续段都只有两张身份图。此方案不使用 `<Picture 3>`、`<Video 1>`，不执行尾帧超分或尾帧驱动调色，也不会在六节提示词前自动插入参考图说明。人物身份参考仍然全局保留；文字承接不保证下一段首帧与上一段尾帧相同。

使用时打开上述工作流，分别选择两张人物图，填写故事 JSON 路径及单段时长，然后运行。旧尾帧版任务的快照和产物保留；继续旧任务仍按其原配置执行，采用本方案应创建新任务。旧提示词若包含第三张图或视频引用，需要按引用的实际用途整理承接文字，不能只机械删除标签。
