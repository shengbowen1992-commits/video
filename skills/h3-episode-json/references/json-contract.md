# 本地画布参数版 JSON 约定

核对日期：2026-10-04。依据：H3 整集项目的 `h3_episode/json_import.py` 与 `render_settings.py`。随包的 `scripts/episode_contract.py` 保存画布参数版的编写约定，默认可离线校验；运行 `--project-root` 可额外核对已安装的实际解析器。如工作流升级，先读实际解析器确认变化。

## 字段

| 位置 | 字段 | 填写规则 |
| --- | --- | --- |
| 顶层 | `version` | 整数 `1` |
| 顶层 | `episode_id` | 1–80 位英文字母、数字、下划线或连字符 |
| 顶层 | `title` | 人可读标题，可中文 |
| 顶层 | `shots` | 1–64 段的数组，按生成顺序排列 |
| 每段 | `id` | 从 `1` 连续递增的整数 |
| 每段 | `duration_sec` | 本 skill 要求显式填写；本地导入器为 5–15 秒，且 `秒数 × 24` 为整数，通常直接用整数秒 |
| 每段 | `first_frame` | 下列两种对象之一；第 1 段只能用图片 |
| 每段 | `prompt` | 完整 I2VA 文本字符串，写对字段名，不写成 `promot` |
| 每段 | `loras` | 本 skill 要求显式填写数组，未指定则 `[]`；单段最多 4 个附加 LoRA |
| 每段 | `seed` | 可省略；需要复现时指定非负整数，解析器上限为 `2**64-1`；避免经 JavaScript 编辑器传递超出其精确整数范围的值 |

## 首帧

图片开场：

```json
{"type": "image", "path": "F:/素材/首帧/001.png"}
```

填写本机真实完整路径；优先正斜杠，支持 PNG、JPG、JPEG、WebP。不能是 URL、相对路径或网络共享。多个角色必须已经在同一首帧画面中。其他人物参考图不能冒充本段的第二、第三输入图。

接上段尾帧：

```json
{"type": "previous_tail"}
```

不要添加 `path`。只接紧邻的上一段，由工作流提取尾部画面作为本段首帧；不是任意外部视频路径，也不是给本段指定终帧。当前默认实现会在前段末尾若干帧内挑清晰帧，不能保证总是最后一个解码帧。该图在本段 prompt 中仍为 `<Picture 1>`。

## 附加 LoRA

```json
[{"name": "替换成ComfyUI已安装的LoRA名称.safetensors", "strength": 0.6}]
```

这是字段示意，不代表此文件存在或推荐强度。名称使用 ComfyUI LoRA 下拉列表的完整值（含相对子目录），不要使用图片式绝对路径。每项只有 `name` 和 `strength`；名称不重复；强度须为 -10 到 10 的有限数值，实际取值按用户设置或作者指导。

每段独立加载自己列出的 LoRA，不自动继承前段。`[]` 表示不加内容 LoRA。画布选择的 4 / 8 步加速 LoRA 另行处理，不能在此重复叠加。

有 LoRA 时：

1. 从本机清单或只读 `/object_info/LoraLoaderModelOnly` 取得准确名称，并核对它确实适用 H3。
2. 从用户信息或作者资料核实触发词；未知就标记未知，不编造，不从文件名猜词。
3. 本地导入器原样传递 `prompt`，不会自动加触发词。需要的词写入当前段视觉正文；保持官方首行和字段顺序。若 LoRA 作者要求与官方首行冲突，说明冲突，不能宣称两者已同时验证。
4. 删除某段 LoRA 时，同步去掉该段仅由它要求的触发词；保留其他 LoRA 或用户正文仍需要的词。

## 时长与导入边界

- 官方提示词 skill 提示 4–15 秒；**此本地导入器仅接受 5–15 秒**。两者区别要写清。
- 本 skill 每段写明 `duration_sec`，覆盖画布默认秒数。调整秒数后，同步调整该段动作密度、对白长度和段内切镜时间。
- 不在 JSON 里写 `width`、`height`、`fps`、`sampling_profile`、`steps`、`default_duration_sec` 或 `default_loras`；默认交付物适配画布参数版。
- 文件上限 2 MiB。不要把整份剧本、素材说明或其他非协议字段塞入 JSON。超过 64 段需要另分文件；新文件第一段必须有真实图片，不能让它的 `previous_tail` 跨文件引用。
- 保存修改后重新上传 JSON；只修改磁盘源文件不会自动替换已上传副本。使用右侧节点“检查”查看配置；是否开始生成按用户当次授权执行。
