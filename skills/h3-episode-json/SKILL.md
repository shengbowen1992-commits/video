# H3 分段视频 JSON

产出实际 UTF-8 `.json` 文件，适配 **H3-整集JSON-外置分辨率与原生加速参数**。这是本地工作流的 JSON 编写 skill；`prompt` 采用 MiniMax 官方 I2VA 规范，外层 JSON 是本地编排器协议，并非 MiniMax 官方 API。

## 工作顺序

1. 读取 [JSON 字段约定](references/json-contract.md) 和 [官方 I2VA 格式摘要](references/i2va-format.md)。修改既有 JSON 时先读取原文件，保留用户内容和段号，按请求另存或覆盖。
2. 从当前对话提取每段剧情、时长、首帧方式、素材路径、对白及 LoRA。已提供的信息不重复询问。未指定时长时可按每段 10 秒起草，并在交付时说明；每段仍须显式写出 `duration_sec`。未指定附加 LoRA 时写 `loras: []`。
3. 使用图片的段落填写真实绝对路径；用图像查看工具检查图片，再写与画面相符的开场。缺少真实路径时询问缺失路径，并继续完成其他段的草稿；不要虚构已存在素材。模板占位路径只能作为明确标注的草稿，不能称为可运行成品。
4. `previous_tail` 段继承前段预期的场景、人物、衣着和物件状态；尾帧尚未生成时明确它是计划，不能声称看过实图。以实际传入的首帧状态为准写后续动作，不假定前段一定精确落在某个姿势。首帧接续不等于运动状态或声音无缝接续。
5. 按参考格式为每段写完整英文 `prompt`，对白、歌词和画面文字保留原语言原文。每段独立从 `<Picture 1>`、`[Shot 1]` 开始。JSON 第 3 段的 prompt 也从 `[Shot 1]` 开始；prompt 内的镜头编号只代表这一段内部的切镜。
6. 用 JSON 序列化器保存文件，正确处理引号与换行，不向 JSON 写入 Markdown 围栏、注释或额外解释。优先使用用户指定位置，否则放在当前工作区的 `generated-json/<episode_id>.json`；避免无关文件覆盖。
7. 运行下方校验，再人工核对动作和对白能否在指定秒数内完成、首帧一致性、LoRA 触发词来源。交付文件链接，以及“段数 / 各段秒数 / 计划总秒数 / 待补素材或未验证项”的简短说明。请求仅是生成 JSON 时，到此完成，不顺带提交视频任务。

## 保留画布控制

生成的 JSON 顶层只放 `version`、`episode_id`、`title`、`shots`；每段放 `id`、`duration_sec`、`first_frame`、`prompt`、`loras` 和可选 `seed`。

分辨率、FPS、原生 / 加速 4 步 / 加速 8 步、原生步数、加速 LoRA 及其强度、偏移和图片适配由画布控制。每段的内容 LoRA 可以写进 JSON；不要把加速 LoRA 塞进该数组。`duration_sec` 明确填写在 `id` 下一行，以便用户直接修改秒数。

默认一段一次连续动作；仅在剧情需要或用户要求时编写段内切镜。对话过长、要求少于 5 秒或超过 15 秒时，指出当前导入器限制并给出可行分段草稿，不悄悄改变用户要求。

## 可复用模板与校验

[三段模板](assets/episode.example.json) 演示图片开场 → 上一段尾帧 → 新图片开场，分别为 8、6、10 秒。图片路径和画面是教学占位，须替换；默认没有附加 LoRA。

本目录可以单独安装，参考资料和脚本都在包内。使用 Python 3.10+，在本 skill 目录运行以下结构检查；也可把脚本路径换成当前安装位置的绝对路径。不会上传、排队或启动 ComfyUI：

```powershell
python -X utf8 scripts/validate_episode.py /path/to/my_episode.json
```

交付可运行文件前，加 `--check-images` 检查图片存在且可解码（需要 Pillow，并在素材所在的机器运行）；服务在线且包含附加 LoRA 时，再加 `--comfy-url http://127.0.0.1:8188`，只读检查 LoRA 名称。服务离线时记录 LoRA 名称尚未核验，不擅自启动服务。工具不核实触发词、画面语义、音画质量或模型兼容性；名称存在也不能证明 LoRA 与 H3 兼容。

默认校验使用随包的 `scripts/episode_contract.py`，只需标准库，检查显式秒数、外置参数边界和 I2VA 格式。若本机已有 H3 整集项目，再传 `--project-root /path/to/h3-episode-json` 额外调用其中 `h3_episode/json_import.py`，验证真实导入器兼容性；它的依赖需由本机项目环境提供。明确报告是否实际调用了该导入器。显式要求的导入器检查失败时直接报告失败，不降级为离线成功。

本 skill 提供 JSON 编写与校验，ComfyUI 工作流、节点、模型及素材是生成视频的外部运行依赖，不包含在技能包内。

修改用户的旧版完整参数 JSON 时，先确认其目标是旧版节点还是画布参数版；本 skill 默认只生成画布参数版，不默默丢弃旧版所需配置。
