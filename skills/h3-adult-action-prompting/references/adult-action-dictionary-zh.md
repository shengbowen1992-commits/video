## 10. H3 动作构句公式

**主体 → 体位 → 主动部位 → 运动方向 → 频率 → 幅度 → 对方身体反馈 → 手部接触 → 表情 → 镜头 → 连续性**

```text
<Subject 2> 位于 <Subject 1> 身后。
<Subject 2> 以稳定而快速的节奏进行连续的前后骨盆运动，
每次动作都具有明显的回撤和向前驱动，形成完整的往复周期。
<Subject 1> 的腰部、臀部、肩部和上半身与每次动作同步前后摇动，
双手持续稳定支撑身体。
摄影机保持前方三分之四中近景并轻微跟随，
始终保持 <Subject 1> 的脸部清晰可见。
整个镜头保持同一姿势、人物身份、身体比例和光线连续。
```
