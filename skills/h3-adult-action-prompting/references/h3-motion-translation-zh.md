# H3 动作转译规则 — 中文

## 为什么要转译

社区 caption 往往很短，例如：

```text
doggy style
pounding
riding
close-up
POV
```

但 H3 更需要把这些标签展开成**可见的身体运动、空间关系和连续时间动作**。

## 每个动作都要拆出的维度

### 1. 体位
例如：
- 后入 / doggy style
- 低位跪趴后入
- 弯腰后入
- 传教士
- 女上位
- 反向女上位
- 面对面跨坐
- 俯卧
- 侧卧
- 站立

### 2. 主动方
必须明确是谁驱动动作。

### 3. 主动身体部位
例如：
- 骨盆 / 臀部
- 上半身
- 腿
- 口交时的头部和嘴部

### 4. 运动方向
例如：
- 前后
- 上下
- 圆周 / 椭圆
- 摇摆

### 5. 频率
例如：
- 慢
- 中速
- 快速 / 高频
- 稳定节奏
- 逐渐加快

### 6. 幅度
例如：
- 小幅
- 中等
- 明显大幅度
- 深入

### 7. 完整动作周期
抽插类动作优先写：

```text
每次向前驱动前都有清晰回撤
```

这样可以避免“快速”被模型理解成原地抖动。

### 8. 接收方身体反馈
如果用户要求高强度动作，至少联动两个身体区域：
- 臀部 / 腰
- 肩部 / 上半身
- 胸部等软组织惯性
- 头部 / 头发次级惯性
- 重心转移

### 9. 稳定支撑点
例如：
- 双手持续撑住床面
- 支撑膝不离开床面
- 抬起的腿持续保持抬起
- 手持续扶住腰 / 大腿 / 后腰

### 10. 镜头
优先使用 H3 自然摄影语言：
- medium close shot
- frontal three-quarter angle
- low-angle shot
- rear-view shot
- POV shot
- tracking shot
- static shot
- push in with small amplitude at slow speed
- arc shot

### 11. 连续性
明确保持：
- 同一体位
- 人物身份
- 身体比例
- 双方空间关系
- 已建立服装状态
- 光线 / 曝光
- 用户要求时保持正脸可见

## 常见 Source → H3 转译

### Source
```text
pounding
```

### H3
```text
以快速、稳定节奏进行连续而有力的前后骨盆运动，
动作幅度明显，每次向前驱动前都有完整回撤。
```

### Source
```text
riding
```

### H3
```text
上方角色通过髋部和腿部主动控制连续重复的上下骑乘周期。
```

### Source
```text
grinding
```

### H3
```text
双方保持贴近，骨盆沿小幅前后或圆周轨迹持续摩擦运动。
```

### Source
```text
bouncing / jiggling
```

### H3
```text
身体重复运动带来自然的软组织次级惯性反馈，
避免机械式抖动。
```

## 正脸优先镜头

当用户强调女主正脸：

```text
摄影机保持前方三分之四中近景，
以小幅度跟随运动，同时始终保持 <Subject 1> 的脸部清晰可见。
她的头部保持适度抬起，不因身体动作掉出画面，
并偶尔直接看向镜头。
```

## 连续性约束

```text
保持同一体位、人物身份、身体比例、双方空间关系、
已建立服装状态和光线连续。
避免多余肢体、重复肢体、身体融合、突然拉远镜头、
或未经要求的体位切换。
```
