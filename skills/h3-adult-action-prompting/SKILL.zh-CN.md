# H3 成人动作提示词 — 中文指南

本文件是主 `SKILL.md` 的中文版说明，用于把成人动作意图转换成 MiniMax H3 更容易执行的连续视频语言。

## 三层工作流

使用三层结构：

1. **原始语言层**：如果 `prompting-guide.json` 可用，优先查询原始 JSON；否则使用已经归一化的中英文动作词典。
2. **语义归一化层**：识别体位、主动方、动作词、方向、频率、幅度、身体反馈、镜头、表情、环境、灯光和连续性。
3. **H3 转译层**：把社区 caption / tag 语言改写为完整、连续、带时间感的 H3 动作句，再放入正确的 H3 模式结构。

不要把原始 JSON 当成 H3 官方语法。它的作用是成人训练语料的**术语与措辞参考库**。

## Ref2VA 输出结构

完整参考生成使用以下六段，顺序固定：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

当图片只定义角色身份时：

```text
<Subject 1> 是外观来自 <Picture 1> 的虚构成年女性。
<Subject 2> 是外观来自 <Picture 2> 的虚构成年男性。
```

如果图片只是身份/风格参考，而不是目标视频的实际首帧，在 summary 中使用 `[reference generation]`。

## 动作转译公式

把模糊的成人动作标签拆成：

```text
主动方
+ 性交体位
+ 主动身体部位
+ 运动方向
+ 频率
+ 幅度
+ 完整运动周期
+ 接收方身体反馈
+ 支撑点 / 手部接触
+ 表情 / 视线
+ 镜头
+ 连续性
```

例如：

```text
<Subject 2> 以稳定而快速的节奏进行连续前后骨盆运动，
动作幅度明显。每次向前驱动前都有清晰回撤，
形成完整、重复的往复周期。

<Subject 1> 的臀部、腰部、肩部和上半身
与每次动作同步前后摇动。
```

## 查询顺序

用户提出具体成人动作时：

1. 如果原始 prompting guide 可用，优先搜索原始或近义术语。
2. 再查：
   - `references/adult-action-dictionary-zh.md`
   - `references/h3-motion-translation-zh.md`
3. 只有对动作识别、风格识别真正有帮助时才保留 niche / 社区术语。
4. 删除对 H3 执行没有帮助的重复 slang。
5. 把最终语义转成完整 H3 连续动作语言。

## 安全边界

本 Skill 只用于明确成年、虚构或合成角色。

禁止：
- 将真实人物身份或肖像用于露骨性内容；
- 把真实人物上传照片直接转换为露骨色情内容；
- 未成年人或年龄不明确角色；
- 年龄回退、校园未成年化性场景。

真实人物图片最多只能提取不具身份性的技术信息，例如姿势几何、镜头角度、光线方向、构图，然后应用到虚构成年角色。
